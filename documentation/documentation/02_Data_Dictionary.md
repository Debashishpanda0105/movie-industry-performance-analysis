# 2. Data Dictionary

## Project Title

**Movie Industry Performance Analysis Using Python & Pandas**

---

## Dataset Overview

The cleaned analytical dataset contains **7,668 movie records** and
**26 columns**.

The dataset includes movie information, release details, audience
metrics, financial metrics, and engineered business features.

# 3. Financial Metrics

## Profit

Profit represents the difference between gross revenue and
production budget.

```text
Profit = Gross Revenue - Budget
```
In the dataset: df_clean["profit"] = df_clean["gross"] - df_clean["budget"]
